# Security policy

Please read [the project security notes](docs/security.md) before sharing logs or describing a suspected issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the maintainer privately through the GitHub profile. Avoid posting exploit details or account data in a public issue.

Security fixes are developed on the current `main` branch. No response-time guarantee or supported-version matrix is currently published.
