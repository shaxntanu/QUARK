## Retrieval notes

The Codex App Server guide was reviewed with the OpenAI documentation skill. Crawl4AI 0.9.5 was used for source retrieval, including the KiCad and hardware workflow review recorded in [research-notes.md](research-notes.md). The official KiCad manual, GitHub Actions security page, Arduino ESP32 release page, and selected GitHub repository metadata were reachable. Some GitHub raw pages and the Espressif PDF body could not be retrieved through Crawl4AI because of timeouts or anti-bot responses. The datasheet URL itself was reachable, but its contents were not treated as reviewed evidence.

## Research boundary

No academic novelty, comparative effectiveness, electrical certification, performance benchmark, or SDG impact claim is made. No external source was used to infer the exact manufacturer or revision of the SuperMini clone, OLED module, LEDs, piezo, or other generic BOM parts.
